# ⚠️ NAME.exe

### *Someone stole your identity. Your name has escaped.*

## 🎮 How to play

1. Type your name and hit **Find it**.
2. The letters break loose and run around the screen. Some hide, some get dizzy, some faint.
3. **Grab each letter and drop it back into its slot**, beat the timer.
4. Win, enjoy the confetti and fanfare, and **download your card** to share.

---

## ✨ Features

| | |
|---|---|
| 🏃 **Letters with personalities** | Letters dodge, hide, crash into each other, get dizzy and faint, all with simple hand-written physics |
| 🖐️ **Drag & drop** | Grab and drop with mouse or touch, with snapping to the nearest free slot |
| 🔊 **Sound, made in code** | Every bonk, sweep and fanfare is generated with the **Web Audio API**: no audio files at all (sound is off until you turn it on) |
| 🗣️ **It talks back** | The game reacts to what you do with short messages and a voice |
| 🎉 **Win screen** | Confetti burst, a fanfare and a title based on your time |
| 🪪 **Shareable card** | Draws a personalised result card on a canvas that you can download as an image |
| 📦 **One file** | Everything lives in a single `index.html`: no build step, no libraries |

---

## 🛠️ Built with

- **HTML5 Canvas** for the result card
- **CSS** animations for the chaos
- **Vanilla JavaScript** game loop (`update` → `render` with `requestAnimationFrame`)
- **Web Audio API** for all sound effects

---

## 🚀 Run it

No install needed. Just open `index.html` in a browser, or play the live version on **[GitHub Pages](https://muzamil112a.github.io/name-exe/)**.

```bash
git clone https://github.com/muzamil112a/name-exe.git
cd name-exe
start index.html   # Windows  (use `open` on macOS)
```
